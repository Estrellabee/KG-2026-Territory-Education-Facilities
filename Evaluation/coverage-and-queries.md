## 2. Coverage measures

Coverage is the ratio between the knowledge atoms required by the purpose
(`KATOM`) and the terms actually present in the produced resource. Numerator and
denominator are stated so that each value can be recomputed.

| Measure | Formula | Value | Meaning |
|---|---|---|---|
| Entity type coverage | `Cov_E = 8/8` | 1.00 | all eight required classes exist in the ontology |
| Object property coverage | `Cov_OP = 2/2` | 1.00 | both required relations exist (`has_municipality`, `has_proximity`) |
| Property anchoring coverage | `Cov_P = 3/13` | ≈ 0.23 | only three of the thirteen project properties found a super-property in an imported fragment (`has_name`, `has_istatCode`, `has_municipality`) |
| UKC anchoring coverage | `Cov_UKC = 17/21` | ≈ 0.81 | seventeen of the twenty-one terminology terms carry a UKC identifier |
| Entity population | `Pop_E = 4/8` | 0.50 | four of the eight classes carry at least one instance |

### Documented gaps (the four terms without a UKC identifier)

| Term | Reason |
|---|---|
| `NaturalLandmark` | no counterpart in the UKC; the concept exists only as a landscape feature |
| `has_municipality` | aligned to `schema:containedInPlace` instead of the UKC |
| `has_proximity` | no external term in any of the three imported fragments |
| `hasEducationalInstitution` | inverse relation, not present in the fragments |

## 6. How to recompute

```sparql
# statements
SELECT (COUNT(*) AS ?n) WHERE { ?s ?p ?o }

# entities per class
SELECT ?class (COUNT(?s) AS ?entities) WHERE { ?s a ?class } GROUP BY ?class

# links
SELECT (COUNT(*) AS ?links) WHERE { ?s <http://knowdive.disi.unitn.it/etype#has_municipality> ?o }
```
